# فرۆشگای ئۆنلاین — پلاتفۆرمی بازرگانی خۆخزمەتگوزار

**پلاتفۆرمێکی تەواوی فرۆشتنی ئێلتڕۆنیک کە لە سێرڤەری خۆت هەڵیدەگریت.**
بۆ ئازادەکانی بچووک و مامناوەند — لە سێرڤەری خۆت دایمەزرێنێ، داتاکانت
خۆت مالکەیان، و بە ئاسانی دەیەوێنیتەوە.

> **زوانەکانی بەڵگەنووسین:**

> [🇬🇧 English](../README.md) ·
> [🇮🇷 فارسی](README-fa.md) ·
> [🇸🇦 العربية](README-ar.md)

## ١. ئەمە چییە

فرۆشگایەکی تەواو لە یەک کۆدبۆکسدا (monorepo-ی npm):

- `apps/api` — API-ی Express.js (TypeScript، ORM-ی Prisma)
- `apps/web` — فرۆشگا و پانێلی بەڕێوەبەرایەتی بە Next.js 14 (App Router، TypeScript)

بە یەک فەرمان لە سێرڤەری کڕیاردایمەزرێنرێت (`./scripts/install-store.sh`)،
بە یەک فەرمان لە دۆخی گەشەپێداندا بجوڵێت (`npm run dev`)، و هەموو
ڕێکخستنەکان لە یەک فایلدایە (`.env.example`).

**لە سەرەتاوە کوردیی سۆرانی لە پلەی سەرەداوە:** فرۆشگا بە ئینگلیزی،
کوردی (سۆرانی)، عەرەبی و تورکی بەردەستە بە پشتگیری تەواوی RTL؛
پانێل و بەڵگەنووسینەکان لە هەمان زوانەکاندان.

## ٢. تایبەتمەندییەکان

### فرۆشگا (بۆ کڕیار)

- کاڵاکان: **فیزیکی و دجیتاڵ** (داگرتن بە توکنی تایبەت بە هەر داوایەک،
  سنووری داگرتن و کاتی هەڵوەشانەوە)، جۆرەکان (variants)، هەڵبژاردنە
  جۆراوجۆرەکان (ڕەنگ/قەبارە...)، وێنەگالێری، ئەنبار، داواکردنی
  پڕکردنەوە، ئاگادارکردنەوەی گەڕانەوەی کاڵا
- گەڕان بە کاتێگۆری (هاوپۆل)، گەڕان (search)، شیکردنەوە بە فاکتەر،
  بەراوردکردن، کەمەکی دەربارەی بینراوەکانی دوایین
- سەبەتە، لیستی دڵخواز، ناونیشانەکان، کڕینی چەند هەنگاویی
- پارەدان: **بە شەرتی سەرەتایەوە کاش و بارودۆخی بانکی** (بێ گەڕان،
  لەلایەن کادڕەوە تەواودەکرێن)؛ **کارتی Stripe هەڵبژاردنییە** بۆ هەر فرۆشگایەک
- داواکان: شوێنکەوتن، پوختەی پارە (receipt)، مێژووی داوا، داگرتنی کاڵای دجیتاڵ
- بۆچوونەکان وێنە هەیە، کوپۆن، کارتی دیاری، داشکاندنەکان
- پەڕە و بلۆگ: سیستەمی ناوەڕۆکی بلۆک-بنەڕەت (سەرنووسە، وێنە، ستوون،
  ناوەڕۆکی گرنگ، وتە، گالێری، دوگمە) بە دابەشکردن/بڵاوکردنەوە و
  سلاگی یونیکۆد
- زوانی فرۆشگا: en / ku / ar / tr بە RTL؛ هەڵبژاردنی دراو و
  پشتگیری چەند دراو
- SEO: داتای سێرڤەر-بنەڕەت، JSON-LD (Product، Breadcrumb، WebSite،
  Article)، sitemap، robots.txt، Open Graph
- دروستکەری پەڕەی سەرەکی (بخشەکان، بنەری، گالێری)

### پانێلی بەڕێوەبەرایەتی (`/admin`)

داشبۆرد، کاڵاکان، جۆرەکان (Variants)، کاتێگۆرییەکان، ئەنبار (موجودی،
ئەنبارەکان، گواستنەوە، مەبەستەکان، هەژمارکردن، یاساکانی پڕکردنەوە،
ئەنباری ناڵەکان)، داواکان، کڕیاران، بۆچوونەکان، کوپۆنەکان، کارتی
دیاری، گەیاندن (ناوچە و ڕێگاکان)، باج، پەڕەکان، بلۆگ، **ڕووکار
(هەڵبژاردنی دیزاین + نیشانەکانی دیزاین)**، بنەر و گالێری، مێنیو،
**شیکاری (Analytics)**، **هێنان و دەرکردن (Import/Export)**،
ڕێکخستنەکان، بەکارهێنەران (پلە: admin، سەرپەرشتیار، customer).

### پلاتفۆرم

- **هێنان و دەرکردنی بەرمیل** بۆ کاڵا و کاتێگۆری (CSV یان JSON،
  پیشاندان، جێبەجێکردنی هەموو-یان-هیچ) — بۆیە بەرگەی ١٠
- **شیکاری و پێشنیاری** (هەڵبژاردنییە، لە سەرەتاوە تایبەتییە) — بۆیە بەرگەی ١١
- **سیستەمی دیزاین**: ٥ دیزاینی ناوخۆیی، ئامرازی scaffold، پیشاندانی ڕاستەوخۆ،
  هەڵبژاردن بۆ هەر فرۆشگایەک — بۆیە بەرگەی ٩
- سنووردارکردنی خێرایی (rate limiting)، شووناسی دروستکردن بە Zod،
  چوونەژوورەوە بە JWT (access + refresh)، وشەی نهێنی بە bcrypt،
  چوارچێوەی چوونەژوورەوە بە پلە (RBAC)
- خزمەتگوزارییە هەڵبژاردنییەکان بە نەرمی کەمی خۆمان نیشان پێدەدەن:
  بەبێ Redis → بێ کێش (cache)؛ بەبێ MinIO → داگرتن لە دیسکی ناوخۆیی؛
  بەبێ SMTP → ئیمەیڵەکان لە لۆگدا نووسران

## ٣. ستاکی تەکنەلۆجیا

| قەبارە | تەکنەلۆژیا |
|---|---|
| فرۆشگا | Next.js 14 (App Router)، React 18، TypeScript |
| دیزاین | CSS variables + نیشانەکانی دیزاین (بۆ هەر دیزاینێک) |
| API | Express.js، TypeScript |
| ORM / بنکەی داتا | Prisma — **لە سەرەتایەوە SQLite** (بێ دامەزراندن)؛ پشتگیری PostgreSQL |
| کێش (Cache) | Redis (هەڵبژاردنییە) |
| فایلی | MinIO / S3 (هەڵبژاردنییە) → دیسکی ناوخۆیی |
| پارەدان | Stripe (هەڵبژاردنییە)؛ بە شەرتی سەرەتایەوە کاش / بارودۆخی بانکی |
| ڕاستەوخۆ | Socket.IO |
| ئیمەیڵ | SMTP (هەر پیشەگەرێک)؛ MailHog بۆ گەشەپێدان |
| تاقیکردنەوە | Vitest (یەکەیی + هاوبەش)، Playwright (سیستەمی CI) |
| بڵاوکردنەوە | Docker / Docker Compose، دامەزراندنی یەک-فەرمانی |

## ٤. دەستپێکی خێرا (دۆخی گەشەپێدان)

**پێویستەکان:** Node.js 18+، npm 9+. بنکەی داتای سێرڤەرپێویست ناکات
(فایلی SQLite خۆی دروست دەکرێت).

```bash
git clone <repository-url> && cd <repository>
npm install

# بنکەی داتا: فایلی SQLite + سکێما دروست بکە، پاشان داتای نموونەیی بنێ
npm run db:deploy        # apps/api/prisma/dev.db
npm run db:seed

# API (:3001) + فرۆشگا (:3000) هاوکات بجوڵێنە
npm run dev
```

> **تێبینی بۆ بنکەی داتای نوێ:** `npm run db:deploy` مایگرەیشنە
> ناوەندەکان جێبەجێدەکات. ئەگەر بنکەی داتای ناوخۆیی بە دوای
> گۆڕانکارییەکدا کێشە بوو، `npm run db:reset` (سڕینەوە + دروستکردنەوە
> + seed) ڕێگای ئاسودەیە. بۆیە [KNOWN_GAPS.md](../KNOWN_GAPS.md) بەرگەی ٩.

### خاڵەکانی گەیشتن

| خزمەتگوزاری | URL |
|---|---|
| فرۆشگا | http://localhost:3000 |
| API | http://localhost:3001 (`/health` بۆ تاقیکردنەوەی تەندروستی) |
| بەڕێوەبەرایەتی | http://localhost:3000/admin |
| پیشاندانی دیزاینەکان | http://localhost:3000/preview/default (و /minimal، /bold، /dawnlight، /pulse) |

### هەژمارە دایمەزرێنراوەکان

| پلە | ئیمەیڵ | وشەی نهێنی |
|---|---|---|
| بەڕێوەبەر | `admin@store.com` | `admin123` |
| کڕیار | `customer@example.com` | `customer123` |

seed هەروەها کاتەڵۆگیکی نموونەیی دروستدەکات (٥ کاتێگۆری لەگەڵ
`General`، ٥ کاڵا، بۆچوون، کوپۆن، ڕێگای گەیاندن، بنەر).

### جوڵاندن بەبێ Docker

هەموو شتێک بەبێ Docker جودەدەچێت. فایلی compose-ی `docker/` بۆ
خزمەتگوزارییە **هەڵبژاردنییەکان** هەیە (Redis، MinIO، MailHog،
PostgreSQL ئەگەر گۆڕی):

```bash
npm run docker:up      # خزمەتگوزارییە هەڵبژاردنییەکان بدەست بکەوە
npm run docker:down    # بێدان
```

## ٥. ڕێکخستن

هەموو ڕێکخستنەکان لە `apps/api/.env`دان (نموونە: `.env.example` لە
ڕیشەی کۆدبۆکس). گرنگترینەکان:

| گۆڕاوە | مەبەست |
|---|---|
| `DATABASE_URL` | `file:./dev.db` (SQLite). دڵنیابە لەگەڵ `provider`-ی `prisma/schema.prisma` یەکخاڵە — جیاوازی هەیە هەڵەی Prisma P1012 دەبێت، هەڵەی ڕێکخستنە نەک خراپیی دامەزراندن |
| `JWT_SECRET` | ٣٢+ پیت؛ دامەزرێنەرەکە توکنی هەڕەمەکی دروستدەکات |
| `REDIS_URL` | هەڵبژاردنییە. نەبوون → کێش بەبێ ئاگادارکردنەوە دادەخرێت |
| `MINIO_*` | هەڵبژاردنییە. نەبوون → بارکردن بۆ دیسکی ناوخۆیی |
| `SMTP_*` / `EMAIL_FROM` | هەڵبژاردنییە. نەبوون → ئیمەیڵ لە لۆگدا دەنووسرێن |
| `STRIPE_SECRET_KEY` / `STRIPE_WEBHOOK_SECRET` | هەڵبژاردنییە. بەتاڵ → پارەدانی کارت شاردنەوەدەکرێت، تەنها ڕەوتی بێگەڕان |
| `FRONTEND_URL` | URL-ی تەواوی فرۆشگا (بەستەرەکان لە ئیمەیڵەکان، گەڕانەوە) |
| `ANALYTICS_TRACKING_ENABLED` | **`false` (سەرەتایی).** `true` کۆکردنەوەی داتای ڕووداوەکان دەستپێدەکات — بۆیە بەرگەی ١١ و پەڕەی تایبەتمەندی |
| `REVIEWS_AUTO_APPROVE` | `false` (سەرەتایی). `true` بۆچوونەکان بەبێ پشکنین بڵاودەکاتەوە |
| `PAYMENTS_ALLOW_MOCK` | `false` (سەرەتایی). `true` هەر کڕیارێک دەتوانێت خۆی پارەدان تەواوبکات — **تەنها بۆ نمایش** |
| `LOG_LEVEL` / `LOG_FILE` | بە شەرتی سەرەتایەوە `info`/`logs/app.log` |

### گۆڕین بۆ PostgreSQL (هەڵبژاردنییە)

1. لە `apps/api/prisma/schema.prisma` بکە `provider = "postgresql"`
2. `DATABASE_URL` بۆ بنکەکەت ڕابکە، بۆ نموونە
   `postgresql://store_user:store_password@localhost:5432/store_db`
   (فایلی compose-ی گەشەپێدانەکان پێشتر یەکێکی لەگەڵ ئەم ناوانە دابیندەکات)
3. `cd apps/api && npx prisma migrate dev` بۆ دروستکردنی سکێمای نوێ

کۆدەکە لە نێوان داتابیسەکان هاوبەشە: فلتەرە ناسراوەکانی SQLite
(`mode: 'insensitive'`) بە کارناوەوە، لەجیاتیان گەڕانی ناوخۆیی
بەکاردێنێت، کەواتە هیچ شتێکی تر نەگۆڕدەرێت. بۆ بەرهەمهاون،
بەردەوام `pg_dump` بکە بۆ پاراستنی بنکەکە.

## ٧. پوختەی ئینجاکتەری (Architecture)

**ڕەوتی داوا (فرۆشگا):** وێبگەڕ → Next.js (کۆمپۆنەنتی سێرڤەر بۆ
پەڕە گرنگەکانی SEO داتاکان لە API وەردەگرێت؛ کۆمپۆنەنتی کلایەنت بۆ
کارلێکدان) → ڕیزبەندی middleware-ی Express (سنووری خێرایی → پارێزانی
JSON → auth → validation-ی Zod) → ڕێگای مۆدیوڵ → سرویس → Prisma →
SQLite/Postgres.

**پڕۆکسی API → وێبگەڕ:** `next.config.js` `/api/*` بۆ API و
`/uploads/*` بۆ MinIO دەگۆڕێت، کەواتە بڵاوکردنەوەی هاوسەرچاوە
بەبێ ڕێکخستنی CORS جودەدەچێت، هەتا ئەگەر هۆستی API بۆ وێبگەڕ
بەردەست نەبێت.

**چوونەژوورەوە:** `POST /auth/login` توکنی **access** + **refresh**-ی
کاتی کورت دەداتەوە. فرۆشگا توکنەکە لە `localStorage` هەڵدەگرێت (بێ
کوکێی شوێنکەوتن — بۆیە بەرگەی ١١). پلەکان: `admin` (هەموو شت)،
`سەرپەرشتیار` (کاتەڵۆگ و داوا، بەبێ بەڕێوەبردنی بەکارهێنەر)،
`customer`.

**پێکهاتەی داتا (سەرەکی):** بەکارهێنەران، کاڵاکان (بە Variants،
ProductImages، Options جۆرەکان)، کاتێگۆرییەکان (درەخەی خۆپەیوەست)،
داواکان + بۆشایی داوا، پارەدانەکان، بۆچوونەکان (و وێنە)، سەبەتە،
لیستی دڵخواز، ناونیشانەکان، کوپۆنەکان، کارتی دیاری، ناوچە/ڕێگای
گەیاندن، باج، ئەنبارەکان + مۆدێلی ئەنبار، پەڕە/بلۆگ (بلۆکەکانی
ناوەڕۆک)، بنەر، مێنیو، ڕێکخستنەکانی فرۆشگا، ڕێکخستنەکانی دیزاین،
UserEvents (شیکاری).

**ڕێساکانی ئاگادارکردنەوە بەکارهاتووە:** خزمەتگوزارییە
هەڵبژاردنییەکان (Redis/MinIO/SMTP) بۆ هەر تایبەتمەندییەک دادەخرێن
بەڵام داوا هەڵنادات؛ شیکاری هەرگیز داوا هەڵنادات؛ نووسینە
بەڕێوەبەرەکان پێش گەیشتن بۆ بنکەکە شوناسیان دەکرێت.

## ٨. ڕێنمایی فرۆشگا (بۆ کارگێڕی فرۆشگا)

- **زیادکردنی کاڵا**: بەڕێوەبەرایەتی → کاڵاکان → *+ کاڵا زیاد بکە*.
  ناو، SKU، نرخ، کاتێگۆری، وێنە پڕ بکە؛ ئەگەر پێویست بوو جۆر یان
  هەڵبژاردن زیاد بکە؛ کاڵای دجیتاڵ URL-ی داگرتن + سنوور وەردەگرێت.
  دۆخی `active` بڵاوی دەکاتەوە.
- **فرۆشتن بەبێ گەیەتی کارت**: لە کڕینەوە کاش و بارودۆخی بانکی
  پێشکەشدەکرێن. داواکان بە `paymentStatus: pending` دەگەن؛ کادڕ لە
  بەڕێوەبەرایەتی → داواکان تەوانیان دەکەن. (`PAYMENTS_ALLOW_MOCK`
  هەرگیز لە فرۆشگای گشتی چالەکەرە.)
- **چالاککردنی Stripe**: دوو کلیل لە `.env` دابنێ، لە داشبۆردی
  Stripe webhook-ی `checkout.session.completed` زیاد بکە، دووبارە
  بدەست بکەوە. هەڵبژاردنی کارت خۆی دەردەکەوێت.
- **کوپۆن و کارتی دیاری**: بەڕێوەبەرایەتی → کوپۆن / کارتی دیاری.
  هەردووکیان لە کڕینەوە جودەدەچێن؛ کارتی دیاری کۆدی دەستبەسەرکردن دروستدەکات.
- **ناوەڕۆک**: بەڕێوەبەرایەتی → پەڕەکان / بلۆگ — دەزگای بلۆک-بنەڕەت
  (زیادکردنی سەرنووسە، وێنە، ستوون، ناوەڕۆکی گرنگ، وتە، گالێری،
  دوگمە)، دابەش → بڵاوکەرەوە. سلاگەکان یونیکۆد-دڵنیان (ناوی
  کوردی/عەرەبی جودەدەچێن).
- **پەڕەی سەرەکی**: بەڕێوەبەرایەتی → داشبۆردی بخشەکان + بنەر و گالێری.

## ٩. دیزاینەکان (Themes)

**دیزاین** دێرێکە لە ژێر `apps/web/themes/<key>/`:

- `theme.json` — لە کاتی **build**دا بە سکیمای Zod-ی تەت پشکنیندەکرێت:
  ناسنامە (key، ناو، ئاهەنگدار، semver)، `features` (`rtl`، `darkMode`،
  `paid`)، `tokens` (ڕەنگەکان، فۆنت، کۆنج، بەرینی کۆنتەینەر، سێبەری
  کارتی، کاڵا لە هەر ڕیزێک، دەستبەسەرکردنی بخشەکان وەک `showTrustBar`)،
  و نەخشەی هەڵبژاردنی `sections`
- `sections/*.tsx` — گۆڕینی کۆمپۆنەنتی بەشی پەڕەی سەرەکی
  (`hero`، `featured`، `categories`). گۆڕین بە تەواوی بەشی پلاتفۆرم
  دەگۆڕێت (هێشتا ڕێگای «wrap» نییە).

**دیزاینە ناوخۆییەکان (٥):** `default`، `minimal` (بە پارە،
سەرەتا-ناوەڕۆک، سەرنووسی serif)، `bold`، `dawnlight`، `pulse`.

**ڕێڕەوی گەشەپێدەر بۆ دیزاینی نوێ:**

```bash
node scripts/scaffold-theme.mjs solar --name "Solar"
```

scaffold هەموو خاڵە پەیوەندیدارەکان جێبەجێدەکات (theme.json + سێ بلۆکی
بەشی RTL-دڵنیا، تۆماری دیزاین، نەخشەی کۆمپۆنەنت، ماتریسی تاقیکردنەوەی
RTL، تاقیکردنەوەی هەڵبژێرەر). پاشان تۆکنەکان و بەشەکان دێمێنە؛
`theme.json`-ی خراپ **build** هەڵدەدات بە ڕێگایەکی ناسراو؛ بیرچوونەوەی
تاقیکردنەوەی RTL تاقیکردنەوەکان هەڵدەدات. لە `/preview/solar` پێشاندان
بکە؛ بۆ هەر فرۆشگایەک لە **بەڕێوەبەرایەتی → ڕووکار** چالاک بکە.
گۆڕینەوەی تۆکنی هەر فرۆشگایەک لە سەر دیزاینی چالاک دەچێت.

**سنوورەکان (ڕاستەقینە):** دیزاینەکان لەگەڵ پلاتفۆرمدا وەرسیۆندەکرێن
(پشکنینی کۆد، بارکردنی ڕاستەوخۆ نییە)؛ `paid: true` تەنها مێتاداتایە
(هێشتا پشکنینی لایسنس یان بازاڕ نییە)؛ `darkMode` تەنها نیشانەی
تایبەتمەندییە.

## ١٠. هێنان و دەرکردنی بەرمیل

تەنها بەڕێوەبەر + سەرپەرشتیار. UI لە `/admin/import-export`؛ API لە
`/api/import-export`.

- **دەرکردن** — `GET /export/:entity?format=csv|json&sample=1` بۆ
  `products` (لەگەڵ variants، وێنە، خانەکانی SEO) و `categories`
  (لەگەڵ بەستەری دایکی). `sample=1` یەک ڕیزی نموونەیی دەگەڕێنێتەوە.
- **پیشاندان** — `POST /preview {entity, format, text}`: پارەکردن +
  پشکنین، هەر ڕیزێک بە **دروستکراو / نوێکراو / هەڵە** جیاکرایەوە،
  هیچ شتێک نانووسێت.
- **جێبەجێکردن** — `POST /commit`: فایلی ڕاستەقینە دووبارە پشکنین
  دەکات و بە **هەموو-یان-هیچ** لە یەک مامەڵەدا جێبەجێدەکات. هەڵەیەکی
  ڕیز → هیچ شتێک نایەوێتەوە.

ڕێساکان: کاڵاکان بە **SKU** یەکخال دەکرێن (نوێ → دروستکردن،
بەردەست → نوێکردنەوە، خانەی بەتاڵ دادەخرێن)؛ کاتێگۆرییەکان بە
**slug پاشان ناو** (بێ دیکەمەندی پیتی گەورە/بچووک)؛ ستوونی
`variants`/`images` ئەگەر هەبوو، ئەوانی پێشتر بە تەواوی دەگۆڕێن.
کاڵا بەبێ ستوونی `category` بۆ کاتێگۆریی دایمەزرێنراوی `General`
دەچێت. سنوور: ١٬٠٠٠٬٠٠٠ پیت / ٢٬٠٠٠ ڕیز بۆ هەر فایلێک.

بە ٢٩ تاقیکردنەوەی هاوبەش، ١٤ تاقیکردنەوەی یەکەیی CSV، ١٢
تاقیکردنەوەی کۆمپۆنەنتی پەڕەی بەڕێوەبەرایەتی، و سکرێپتی ڕاستەوخۆی CI
`scripts/verify-import-export.py` پشتڕاستکراوەتەوە.

## ١١. شیکاری، پێشنیاری و تایبەتمەندی

**لە سەرەتایەوە دادەخرێت.** هەموو ڕەوتی ڕووداوەکان تەنها کاتێک
چالاک دەبێت کە API لەگەڵ `ANALYTICS_TRACKING_ENABLED=true` بجوڵێت؛
بەبێ ئەم نیشانەیە ڕێگاکانی شوێنکەوتن 404 دەگەڕێنەوە و **هیچ شتێک
نەکۆدرێت** (داوای ڕووداوی فرۆشگا بە بێدەنگی بەسردەخرێن).

کاتێک چالاکە:

- **ڕووداوەکان**: `view`، `add_to_cart`، `wishlist` لە فرۆشگا
  (ناسنامەی سیشن لە `sessionStorage` — هەرگیز کوکێ نییە؛ توکنی
  bearer تەنها کاتێک بەکارهێنەر چوویتەژوورەوە بەردەستە، کەواتە
  ڕووداوەکان بە هەژمارەوە دەبەسترێن)؛ `search` و `purchase` لە
  لایەنی سێرڤەرەوە تۆمار دەکرێن (ڕێگای گەڕان، دروستکردنی داوا).
  هەر ڕووداوێک جۆری ڕووداو، کاڵا/کاتێگۆری، دەقی گەڕان، کات،
  user agent و IP-ی کلایەنت تۆماردەکات.
- **بەکارهێنەران**: **Trending**-ی پەڕەی سەرەکی (بنەڕەتی ڕووداوەکان)،
  **چالاکیی فرۆشگا** لە بەڕێوەبەرایەتی (ژمارەکانی ئەمڕۆ، گەڕانی
  سەرەکی ٣٠ ڕۆژ، ترێندی ٧ ڕۆژ)، **ڕێژەی گۆڕان** بۆ هەر کاڵایەک
  (بینین → سەبەتە → کڕین)، ڕەفتاری بەکارهێنەر، و **مۆتەری
  پێشنیاری** (also-bought لە هاوکڕینە ڕاستەقینەکان فێردەبێت؛
  پێشنیاری بنەڕەتی مێژوو لە بینینەکان).
- **هەرگیز ناکەین**: بە شەرتی سەرەتایەوە بەبێ شیکاریی سێتەم؛
  (Google Analytics تەنها ئەگەر خاوەنی فرۆشگا property id
  ڕێکبخات)، فرۆشتن یان هاوبەشکردنی داتا، کوکێی شوێنکەوتن —
  دۆخی چوونەژوورەوە و هەڵبژاردنەکان لە `localStorage`-ی وێبگەردان.
- **لۆگی سێرڤەر** هەمیشە IP-ی کلایەنت هەڵدەگرێت (لۆگی ستانداردی
  وێب)؛ دەقی گەڕان تەنها لە `LOG_LEVEL=debug` لە لۆگدا دەردەکەوێت.

پەڕەی `/privacy` هەموو ئەمانە بەڵگەدەکاتەوە و تێبینی پاراستن هەیە:
ئەگەر ڕەفتارەکە بگۆڕدرێت، پەڕەکە لە هەمان کۆمیتدا دەگۆڕدرێت.

## ١٢. پوختەی API

REST، JSON، لە شوێنی پێویست JWT-پارێزراو. بنکە: `/api`.

- **Auth**: تۆمارکردن، چوونەژوورەوە، refresh، دەرچوون، me،
  بیرچوونەوە/نوێکردنەوەی وشەی نهێنی
- **کاڵاکان**: لیست (فلتەری فاکتەر + گەڕان)، تایبەتمەند، `search`،
  بە id/slug، پەیوەندیدار، CRUD (بەڕێوەبەر)، variants و options
- **داواکان**: لیست، دروستکردن، نوێکردنەوەی دۆخ (بەڕێوەبەر)،
  هەڵوەشاندنەوە، receipt، شوێنکەوتن، توکنی داگرتن بۆ هەر بۆشاییەک
- **پارەدان**: process (تەواوکردنی کادڕ)، Stripe Checkout + webhook
- **بەکارهێنەر / کڕیار**: CRUD (بەڕێوەبەر)، داوا و لیستی دڵخوازی
  هەر بەکارهێنەرێک
- **کارگێڕی کاتەڵۆگ**: کاتێگۆرییەکان (درەخە)، ئەنبار و
  ئەنبارەکان، کوپۆن، کارتی دیاری، گەیاندن، باج
- **ناوەڕۆک**: پەڕەکان، بلۆگ، بنەر، مێنیو، بخشەکانی سەرەکی،
  ڕێکخستنەکان، دیزاین
- **کارگێڕی فرۆشگا**: `import-export` (بەرگەی ١٠)، `analytics`
  (بەرگەی ١١)، `recommendations` (trending، نوێکان، also-bought،
  bought-together، مێژوو، تایبەتمەند)، `downloads`، `currency`،
  `storage` (بارکردن)
- **تەندروستی**: `GET /health`

سەرچاوەی ڕاستەقینە: `apps/api/src/modules/*/…routes.ts` (هەر ڕێگایەک
تاقیکردنەوەی یەکەیی/هاوبەش هەیە یان سکرێپتی ڕاستەوخۆی `verify-*.py`).

## ١٣. بنکەی داتا

**لە سەرەتایەوە: SQLite** (`apps/api/prisma/dev.db`) — بێ
دامەزراندن؛ فایلەکە بە `npm run db:deploy` دروست دەکرێت. PostgreSQL
بە تەواوی پشتگیریکراوە (بۆیە بەرگەی ٥).

```bash
npm run db:deploy     # جێبەجێکردنی مایگرەیشنەکان (migrate deploy)
npm run db:migrate    # گەشەپێدان: دروستکردن/جێبەجێکردنی مایگرەیشن
npm run db:seed       # کاتەڵۆگی نموونەیی + هەژمارەکان
npm run db:reset      # سڕینەوە، دروستکردنەوە، seed
npm run db:studio     # GUI-ی Prisma Studio
npm run db:generate   # دووبارە دروستکردنی کلاینت دوای گۆڕینی سکێما
```

کەمی دۆزراوە: کۆمەڵی مایگرەیشنی دایمەزرێنراو لە هەندێک
گۆڕانکاریی سکێما دواکەوتووەتەوە (دۆخی ڕاستەقینە لە
[KNOWN_GAPS.md](../KNOWN_GAPS.md) بەرگەی ٩) — بۆ بنکەی داتای ناوخۆیی
یە نوێ، `db:reset`/`prisma db push` + seed ڕێگای ئاسودەیە.

## ١٤. تاقیکردنەوە و CI

| سیستەم | فەرمان | پێویستی |
|---|---|---|
| یەکەیی API | `npm run test:api:unit` | هیچ (Vitest) |
| هاوبەشی API | `npm run test:api:integration` | هیچ — **mock-Prisma** ناوخۆیی، بەبێ داتابیس |
| lib-ی وێب | `npm run test:web:lib` | هیچ (Vitest + happy-dom) |
| کۆمپۆنەنتی وێب | `npm run test:web:components` | هیچ (RTL + happy-dom) |
| regression-ی ڕاستەوخۆ (API) | `bash scripts/regression.sh` | API-ی جودەچوو + داتای seed |
| regression-ی ڕاستەوخۆ (وێبگەڕ) | `ui-checks`-ی CI | API + فرۆشگای دروستکراو، Playwright |
| هەڵسەنگێنەری تایبەتمەندی | `python3 scripts/verify-*.py` | API-ی جودەچوو (+ فرۆشگا بۆ ئەوانی وێبگەڕ) |

CI (`.github/workflows/ci.yml`) لە هەر push-ێک بۆ `main` دوو کارە
هاوکات جێبەجێدەکات: **api-checks** (مایگرەیشن، seed، دەستپێکردنی API،
`regression.sh`، `verify-import-export.py`، هەڵسەنگێنەری commerce/theme/
users/404/dashboard) و **ui-checks** (`next build` + سیستەمی وێبگەڕ:
گەڕانی پەڕەکان، دروستکەری سەرەکی، بنەر، 404، بەکارهێنەران، داشبۆرد،
پەڕەکان، بلۆگ، جیۆمەتریی سایدبار، سلاگی یونیکۆد).

## ١٥. بڵاوکردنەوە

**دامەزراندنی کڕیار (پێشنیاریی):** لە سێرڤەری Docker —

```bash
git clone <repo> /opt/store && cd /opt/store
./scripts/install-store.sh     # compose (پڕۆفایل بەرهەمهاون) + seed، یەک فەرمان
```

دامەزرێنەرەکە `JWT_SECRET`-ی هەڕەمەکی نوێ دروستدەکات،
`docker-compose.prod.yml` build دەکات (api + web + postgres + redis +
minio + mailhog)، لە یەکەم دەستپێکدا بنکەکە یەکخاڵدەکات و بە
دەرەوەی کۆنتەینەری API seed دەکات. وردەکاری تەواو:
**[DEPLOYMENT.md](DEPLOYMENT.md)** (مۆد A Docker، مۆد B
بەبێ Docker).

**دەستی:** `npm run build && npm run start` (یان Dockerfiles-ی
`Dockerfile.api` / `Dockerfile.web`). فرۆشگاکە لە دوار TLS دابنێ؛
پێش دەستپێکی گشتی `FRONTEND_URL`، `CORS_ORIGIN`، SMTP و (بە
هەڵبژاردن) Stripe لە `apps/api/.env` دابنێ.

## ١٦. چارەسەری کێشەکان (پوخت)

| نیشانە | هۆ و چارەسەر |
|---|---|
| `the URL must start with the protocol 'file:'` (P1012) | `DATABASE_URL` لەگەڵ `provider`-ی سکێما یەکخاڵ نییە (sqlite پێویستی `file:` هەیە). یەکخاڵیان بکە — هەڵەی ڕێکخستنە، نەک خراپیی دامەزراندن |
| فرۆشگا جودەدەچێت بەڵام «پەڕە نەدۆزرایەوە» لە پەڕەی بڵاوکراوەوە | تەنها **404-ی دیاریکراوی API** not-found پیشاندەدات؛ کێشەی API پەڕەی هەڵەی کاتی دەردەخات (fail-open، بە دیزاین) |
| 500 بۆ PDP لە کاتی داوا | `og:type` بپشکنە — Next.js `"product"` ناقبوڵکات؛ کۆدەکە بە قیوەتە ڕێگەپێدراوەکان بەکاردەهێنێت |
| پەڕەی بەڕێوەبەرایەتی بەبێ داتا دەردەکەوێت | API ناجوڵێت، یان `NEXT_PUBLIC_API_URL` هۆستێکە وێبگەڕ ناگاتە ئەو — ئەپی وێب `/api` هاوسەرچاوە پڕۆکسیدەکات (بۆیە بەرگەی ٧) |
| هەڵبژاردنی کارت لە کڕینەوە نەماوە | کلیلەکانی Stripe دانانراون (یان webhook نەماوە) — چاوەڕوانکراوە: فرۆشگا دەگەڕێتەوە بۆ ڕەوتی بێگەڕان |
| ئیمەیڵەکان «نەنێردران» | SMTP ڕێکنەخراوە → لە لۆگدا دەنووسرێن (بپشکنە `LOG_FILE`). لە ناوخۆ MailHog بەکاربهێنە |
| داتای کۆن دوای گۆڕانی سکێما | لە ناوخۆ `npm run db:reset`؛ بۆ کۆمەڵی مایگرەیشن `scripts/sync-migrations.sh` |

مێژووی تەواوی چارەسەرەکان لە gitدایە؛ کەمییە ئێستایەکان لە
[KNOWN_GAPS.md](../KNOWN_GAPS.md)دان.
